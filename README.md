## Adam Sebhat

I build AI-powered web products for small businesses — the kind of companies that get priced out
of custom software. Most of my work is Next.js and TypeScript on the front, with Claude doing the
parts that used to need a person.

Currently running [Savowai](https://savowai.com), a one-person studio doing exactly that.

### Selected work

**[savowai-app](https://github.com/Savowai/savowai-app)** — an agency operations dashboard where
four AI agents run the client pipeline end to end: find a lead, research it, write the outreach,
build the site. A human approves every stage. Next.js 16, React 19, Claude, Airtable.

The interesting problem here wasn't calling an LLM — it was deciding what happens when one fails.
Generation errors are rejected rather than saved, because a half-built page sent to a real business
is worse than no page at all.

**[savowai-website](https://github.com/Savowai/savowai-website)** — the studio's marketing site.
Next.js 16, Framer Motion, Airtable intake. The testimonials section deliberately renders nothing
until real client reviews exist.

**[medlink-transport](https://github.com/Savowai/medlink-transport)** — a booking and information
site for a non-emergency medical transportation service in King & Snohomish County, WA. Built
around wheelchair accessibility and patients scheduling by phone.
